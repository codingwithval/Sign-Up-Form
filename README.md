# Sign Up Form

This is my sign up form project from The Odin Project. It's a simple page where a new user can enter their details to create an account.

## About the Project

In this project, we were asked to build a sign up page using HTML and CSS. The page is split into two sections. The left side has a banner area with a logo and a short message, and the right side has the form where people fill in their details.

I used Flexbox to arrange everything on the page, from the two main sections down to the form fields and buttons. I also designed my own logo as an SVG, so it stays sharp at any size.

The form includes fields for first name, last name, email, phone number, and password (plus a confirm password field), along with a button to create the account and a link for people who already have an account.

## What I Practiced

- Building a form with labels and different input types
- Using Flexbox to lay out the page and line things up neatly
- Creating a logo as an SVG and adding it to the page
- Styling inputs, buttons, and focus states so the form is easy to use
- Making the page look balanced on different screen sizes
- Keeping my HTML organized and my CSS tidy

## What I Learned

This project helped me get more comfortable with how forms work and how to make them look clean and user friendly. Flexbox started to feel a lot more natural as I used it to position things and control spacing. Making my own SVG logo was a fun extra, and it showed me how images can be built with code rather than just added as files.
